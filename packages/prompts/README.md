# `@casevault/prompts` — versioned prompt registry (placeholder)

Prompt templates with version metadata, per Technical Spec §12.4.

Each prompt file must track: name, version, intended use, required inputs,
allowed source classes, output schema (see `schemas/`), review warnings.

Directories: `chronology/`, `claims/`, `review/`, `drafting/`, `red_team/`,
`schemas/` (structured output contracts).
